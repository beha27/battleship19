# ⚔️ Морской Бой 10×10 (PvP & PvE)

Современная автономная веб-игра **«Морской Бой»**.

## 🏆 Условие окончания игры
Игра отслеживает количество пораженных палуб. Поскольку во флоте 10 палуб (4 + 3 + 2 + 1):
- При уничтожении 10-й палубы соперника всплывает модальное окно **🏆 ПОБЕДА!**
- Если соперник первым уничтожит 10 палуб вашего флота, выводится окно **💀 ПОРАЖЕНИЕ...** с кнопкой перезапуска реванша.
